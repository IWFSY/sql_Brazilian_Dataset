## 🔓Добро пожаловать в репозиторий sql_data_warhouse_project_amazon, проектирование аналитического DWH на базе Amazon Sales Dataset.   
Это проект для портфолио, его суть в демонстрации навыков создания хранилищ данных и получения из них аналитических метрик для бизнеса. 

## 🏅**Архитектура проекта:**
Проект создан по архитектуре Medallion, включает в себя таблицы слоев Bronze и Silver, а также представление слоя Gold.
- Бронзовый слой содержит одну исходную таблицу в сыром виде, формат csv.
- Серебряный слой это деление исходной таблицы на отдельные таблицы фактов и измерений, с последующей очисткой и стандартизацией данных.
- Золотой слой действует в виде представления на основе данных из серебряного слоя. Включает в себя окончательные метрики, готовые для анализа бизнеса.

## 🔎**Обзор проекта:**
Проект на базе СУБД MS Server, включает в себя работу с архитектурой данных, их преобразованием, разработку новых таблиц и оптимизацию аналитических запросов.
Также сожержит схему моделей, потоков и каталоги данных.

## 📢**Требования к проекту**

### Создание хранилища данных (Data Engineering) 

#### Цель: 
Разработать современное хранилище данных с использованием SQL Server для консолидации данных о продажах, что позволяет вести аналитическую отчетность и принимать обоснованные решения. 

#### Технические характеристики 
- **Источник данных**: Импорт данных из исходной системы, представленных в формате CSV-файла. 
- **Качество данных**: очищать и разрешать проблемы с качеством данных перед анализом. 
- **Scope**: Фокус только на последнем наборе данных; Историзация данных не требуется. 
- **Документация**: Предоставить чёткую документацию модели данных для поддержки как бизнес-заинтересованных сторон, так и аналитических команд. 

--- 

### BI: Аналитика и отчётность (анализ данных) 

#### Цель:
Разработать аналитику на базе SQL для предоставления подробных инсайтов по: 
- **Поведение клиентов** 
- **Производительность продукта** 
- **Тенденции продаж**
