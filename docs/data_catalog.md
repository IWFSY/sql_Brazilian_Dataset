# Каталог данных золотого слоя

## Overview
Золотой уровень — это модель данных для интеграции в приложение для бизнес аналитики (Power BI).

---

### 1. **gold.fact_mart**
- **Цель:** Таблица фактов, включающая информацию о заказах и объединяющаяю измерения продавцов, клиентов и продуктов. Гранулярность на уровне количества платежей в рамках товаров в заказе.
- **Список колонок:**

| Название колонки              | Тип даннных     | Описание                                                                                    |
|-------------------------------|---------------|-----------------------------------------------------------------------------------------------|
| customer_key                  | INT           | Цифровой суррогатный ключ для связи с измерением клиентов (gold.dim_customers_mart)           |
| product_key                   | INT           | Цифровой суррогатный ключ для связи с измерением продуктов (gold.dim_products_mart)           |
| seller_key                    | INT           | Цифровой суррогатный ключ для связи с измерением продавцов (gold.dim_sellers_mart)            |
| order_id                      | VARCHAR(32)   | Уникальный идентификатор заказа                                                               |
| order_item_id                 | INT           | Порядковый номер позиции товара в чеке                                                        |
| payment_method                | VARCHAR(15)   | Тип оплаты (Credit card, Boleto, Voucher, Debit card)                                         |
| payment_type                  | INT           | Порядковый номер транзакции в рамках одного чека                                              |
| payment_sequential            | INT           | Порядковый номер транзакции в рамках чека                                                     |
| payment_installments          | INT           | Количество месяцев предоставленной рассрочки                                                  |
| price                         | DECIMAL(10,2) | Чистая стоимость одной единицы товара                                                         |
| freight_value                 | DECIMAL(10,2) | Стоимость доставки одной единицы товара                                                       |
| payment_value                 | DECIMAL(10,2) | Полная стоимость товаров по чеку                                                              |
| order_status                  | VARCHAR(15)   | Текущий статус заказа (Delivered, Canceled)                                                   |
| shipping_limit_date           | DATE          | Дата, до которой продавец обязан передать товар логистам                                      |
| order_purchase_date           | DATE          | Дата создания заказа                                                                          |
| order_approved_at             | DATE          | Дата подвтерждения заказа                                                                     |
| order_delivered_carrier_date  | DATE          | Дата передачи в службу доставки                                                               |
| order_delivered_customer_date | DATE          | Дата вручения заказа                                                                          |
| order_estimated_delivery_date | DATE          | Планируемая дата доставки                                                                     |
---

### 2. **gold.customers_mart**
- **Цель:** Транзакционная бизнес-витрина, предназначенная для CRM-аналитики и оценки клиентской ценности (LTV). Содержит детальную историю покупок, обогащённую поведенческими метриками (жизненный цикл, частота отмен, финансовые траты и предпочтительные методы оплаты).
- **Список колонок:**

| Название колонки              | Тип даннных   | Описание                                                                                      |
|-------------------------------|---------------|-----------------------------------------------------------------------------------------------|
| customer_key (PK)             | INT           | Цифровой суррогатный ключ                                                                     |
| customer_unique_id            | VARCHAR(32)   | Уникальный идентификатор личного кабинета покупателя (для связи между заказами)               |
| order_id                      | VARCHAR(32)   | Идентификатор конкретного заказа клиента                                                      |
| customer_city                 | VARCHAR(50)   | Город проживания покупателя                                                                   |
| customer_state                | CHAR(2)       | Двухбуквенный код штата Бразилии                                                              |
| payment_sequential            | INT           | Порядковый номер транзакции в рамках чека                                                     |
| payment_installments          | INT           | Количество месяцев рассрочки для конкретной оплаты                                            |
| price                         | DECIMAL(10,2) | Стоимость конкретного товара в заказе                                                         |
| payment_value                 | DECIMAL(10,2) | Общая сумма по чеку                                                                           |
| order_purchase_timestamp      | DATETIME      | Дата и время оформления заказа                                                                |
| order_delivered_customer_date | DATETIME      | Фактическая дата и время вручения заказа покупателю                                           |
| first_order                   | DATETIME      | Дата самого первого заказа клиента в истории платформы                                        |
| last_order                    | DATETIME      | Дата последнего совершенного заказа клиента на текущий момент                                 |
| months_lifespan               | INT           | Текущее время жизни клиента на платформе (в месяцах между первой и последней покупкой)        |
| total_orders                  | INT           | Общее количество уникальных заказов, сделанных покупателем за всё время                       |
| total_spent                   | FLOAT         | Совокупные исторические затраты покупателя                                                    |
| payment_type                  | VARCHAR(15)   | Способ оплаты (Credit card, Voucher, Boleto, Debit card)                                      |
| preferred_payment_type        | VARCHAR(11)   | Самый популярный способ оплаты у этого клиента (определяется по частоте транзакций)           |
| canceled_percent              | FLOAT         | Доля отмененных заказов клиента от общего числа его покупок (%)                               |
---

### 3. **gold.products_mart**
- **Цель:** Коммерческая бизнес-витрина, предназначенная для анализа продаж, сезонности спроса и контроля логистических издержек. Объединяет физические параметры товаров (габариты, вес, медиа-контент) с финансовыми результатами, позволяя оценивать долю затрат на доставку в цене товара.
- **Список колонок:**

| Название колонки              | Тип даннных   | Описание                                                                                      |
|-------------------------------|---------------|-----------------------------------------------------------------------------------------------|
| product_key (PK)              | INT           | Цифровой суррогатный ключ                                                                     |
| order_id                      | VARCHAR(32)   | Идентификатор заказа, в рамках которого был продан товар                                      |
| order_item_id                 | INT           | Порядковый номер (индекс) товарной позиции в чеке                                             |
| product_category_name         | VARCHAR(50)   | Название товарной категории                                                                   |
| price                         | DECIMAL(10,2) | Чистая стоимость одной физической единицы товара                                              |
| freigh_value                  | DECIMAL(10,2) | Стоимость доставки одной единицы товара                                                       |
| order_date                    | DATE          | Дата совершения покупки                                                                       |
| order_months                  | INT           | Порядковый номер месяца совершения заказа (1–12) для анализа сезонности                       |
| order_quarter                 | INT           | Номер квартала совершения заказа (1–4) для макро-отчетности                                   |
| order_day_of_week             | INT           | День недели совершения заказа (1–7) для выявления недельной цикличности спроса                |
| product_photos_count          | INT           | Количество фотографий в карточке товара                                                       |
| product_weight_grams          | DECIMAL(10,1) | Вес товара в граммах                                                                          |
| product_lenght_cm             | DECIMAL(10,1) | Длина товара в сантиметрах                                                                    |
| product_height_cm             | DECIMAL(10,1) | Высота товара в сантиметрах                                                                   |
| product_width_cm              | DECIMAL(10,1) | Ширина товара в сантиметрах                                                                   |
| total_item_cost               | DECIMAL(38,2) | Совокупная стоимость всех единиц данного товара                                               |
| total_order_shipping_cost     | DECIMAL(38,2) | Общая стоимость доставки всех позиций                                                         |
| shipping_to_price_ratio       | FLOAT         | Соотношение стоимости доставки к цене товара (%)                                              |
| is_free_shipping              | INT           | Флаг бесплатной доставки для покупателя (1 — бесплатно, 0 — платно)                           |
---

### 4. **gold.logistics_mart**
- **Цель:** Операционная бизнес-витрина, предназначенная для контроля уровня сервиса, мониторинга сроков доставки и выявления этапов сбоя в цепочке поставок. Позволяет сопоставлять плановые дедлайны с фактическими датами отгрузки и вручения, автоматически определяя виновную в задержке сторону (продавец или транспортная компания).
- **Список колонок:**

| Название колонки              | Тип даннных   | Описание                                                                                      |
|-------------------------------|---------------|-----------------------------------------------------------------------------------------------|
| seller_key (PK)               | INT           | Цифровой суррогатный ключ                                                                     |
| customer_key (PK)             | INT           | Цифровой суррогатный ключ                                                                     |
| order_id                      | VARCHAR(32)   | Уникальный идентификатор заказа                                                               |
| order_datetime                | DATETIME      | Дата и время оформления заказа покупателем                                                    |
| payment_datetime              | DATETIME      | Дата и время официального подтверждения оплаты заказа банком                                  |
| shipping_date                 | DATETIME      | Дата и время передачи собранного товара на склад курьерской службы                            |
| delivery_date                 | DATETIME      | Дата и время вручения посылки конечному покупателю                                            |
| estimated_delivery            | DATE          | Обещанная маркетплейсом дата доставки (плановый дедлайн для клиента)                          |
| shipping_deadline             | DATETIME      | Крайний срок, до которого продавец обязан собрать и отгрузить товар в доставку                |
| actual_delivery_days          | INT           | Реальное количество дней, которое посылка провела у курьерской службы                         |
| seller_handling_days          | INT           | Время обработки заказа продавцом (дней от подтверждения оплаты до отгрузки перевозчику)       |
| delivery_delay_days           | INT           | Общее количество дней опоздания доставки относительно плановой даты estimated_delivery        |
| delay_responsible_party       | VARCHAR(13)   | Ответственная за просрочку сторона (Carrier Delay — служба доставки, Seller Delay — продавец) |
| seller_avg_delivery_days      | INT           | Средний срок доставки товаров у данного конкретного продавца                                  |
| city_avg_delivery_days        | INT           | Средний срок доставки посылок для города, из которого уехал товар (контекст региона)          |
| deadline_violation            | VARCHAR(3)    | Статус нарушения продавцом своего личного лимита отгрузки (Yes / No)                          |
---

### 4. **gold.seller_mart**
- **Цель:** Бизнес-витрина, агрегированная до уровня уникального ключа продавца. Предназначена для оценки эффективности торговых партнеров, классификации селлеров и контроля качества их работы. Объединяет географический контекст, финансовые показатели объемов продаж и метрики операционной надежности.
- **Список колонок:**

| Название колонки              | Тип даннных   | Описание                                                                                      |
|-------------------------------|---------------|-----------------------------------------------------------------------------------------------|
| seller_key (PK)               | INT           | Цифровой суррогатный ключ                                                                     |
| seller_city                   | VARCHAR(50)   | Город регистрации или расположения склада продавца                                            |
| seller_state                  | CHAR(2)       | Двухбуквенный код домашнего штата продавца                                                    |
| total_revenue                 | DECIMAL(38,2) | Чистая совокупная выручка продавца от продажи самих товаров за всю историю                    |
| total_shipping_revenue        | DECIMAL(38,2) | Общая сумма стоимости доставки для конкретного продавца                                       |
| gross_merchendise_value       | DECIMAL(38,2) | Общий торговый оборот продавца, стоимость доставки + сумма свыручки                           |
| total_orders                  | INT           | Количество уникальных заказов, успешно обслуженных продавцом                                  |
| total_item_sold               | INT           | Физическое количество штук проданного товара                                                  |
| items_per_order               | FLOAT         | Средняя глубина корзины (количество единиц товара в одном уникальном заказе продавца)         |
| first_sale_date               | DATETIME      | Дата и время совершения самой первой продажи на платформе                                     |
| last_sale_date                | DATETIME      | Дата и время последней зафиксированной коммерческой активности продавца                       |
| seller_lifespan_months        | INT           | Общие время жизни продавца на платформе, в месяцах                                            |
| cancellation_rate             | FLOAT         | Процент отмененных заказов от общего числа (%)                                                |
